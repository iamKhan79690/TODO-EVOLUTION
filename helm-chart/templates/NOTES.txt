FRONTEND ACCESS:

  The frontend service is of type {{ .Values.frontend.service.type }}.

  {{- if eq .Values.frontend.service.type "LoadBalancer" }}
  Get the LoadBalancer IP/host:
    $ kubectl get svc todo-evolution-frontend

  If using Minikube, get the URL:
    $ minikube service todo-evolution-frontend --url
  {{- else if eq .Values.frontend.service.type "NodePort" }}
  Get the NodePort:
    $ kubectl get svc todo-evolution-frontend
  {{- else }}
  Access via port-forwarding:
    $ kubectl port-forward svc/todo-evolution-frontend 8080:80
  {{- end }}

BACKEND API:

  The backend service is available at:
    http://todo-evolution-backend:8000

MCP SERVER:

  The MCP server is available at:
    http://todo-evolution-mcp-server:8001

SECRETS:

  Before deployment, update the todo-secrets Secret with:
  - DATABASE_URL: PostgreSQL connection string
  - JWT_SECRET: Secure random string (min 32 chars)
  - OPENAI_API_KEY: Your OpenAI API key

  Example:
    $ kubectl create secret generic todo-secrets \
      --from-literal=DATABASE_URL="postgresql+asyncpg://..." \
      --from-literal=JWT_SECRET="your-secret-here" \
      --from-literal=OPENAI_API_KEY="sk-your-key-here"

HEALTH CHECKS:

  Frontend health: http://todo-evolution-frontend/api/health
  Backend health:  http://todo-evolution-backend/health/
  MCP health:      http://todo-evolution-mcp-server/health

DATABASE:

  This chart assumes an external PostgreSQL database.
  You can deploy PostgreSQL using:
    $ helm install postgres bitnami/postgresql \
      --set auth.database=todo \
      --set auth.password=todo123 \
      --set auth.user=todo_user

  Then update the DATABASE_URL in the todo-secrets Secret.
